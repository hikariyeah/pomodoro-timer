# 🍅 番茄钟计时器 · Pomodoro Timer

一个**纯网页版**的番茄工作法计时器 —— 单个 HTML 文件，**双击即开即用**，无需安装、无需联网、无需注册。专注、休息、记录，一个文件全搞定。

> 👉 详细图文使用说明见 [番茄钟使用指南.md](番茄钟使用指南.md)

---

## ✨ 特点

### 🌐 网页版，零依赖
- 一个 `pomodoro-timer.html` 文件就是全部，HTML + CSS + JS 全部内联。
- 不需要 `npm install`、不需要服务器、不需要打包。

### ⚡ 即开即用
- **双击打开**就能用，离线也能跑（响铃声为程序合成，无需音频文件）。
- 复制到任何电脑、U 盘、网盘都能直接运行。

### ⏱ 时间灵活设置
- 专注 / 短休息 / 长休息时长都可自由调整。
- 可设置「每几轮专注后进入长休息」。
- 完成自动响铃、自动切换下一阶段，背景配色随模式变化。
- 快捷键：`空格` 开始/暂停，`R` 重置。

### 💾 数据存储与备份
- 每个番茄的**完成 / 休息 / 中断**都会被记录，并按「今天 / 昨天 / 日期」分组展示。
- 数据自动保存在浏览器本地，**关掉再打开依然在**。
- 支持 **导出 / 导入** JSON 备份文件，换设备也能恢复。
- 支持 **连接本地文件自动同步**（Chrome / Edge），记录实时写入你指定的 `.json` 文件。

---

## 🚀 使用方法

1. 下载 `pomodoro-timer.html`。
2. 双击用浏览器打开。
3. 点「开始」，专注起来 🍅。

就这么简单。
